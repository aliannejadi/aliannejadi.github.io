data & code

Datasets, benchmarks, and code released with our papers. Every publication with released code also has a "code" button on the publications page.

Benchmarks and test collections

  • Total Recall QA (SIGIR 2026): a verifiable evaluation suite for deep research agents.
  • TREC iKAT (2023–2025): test collections for personalized conversational search. 2023 collection and tools: GitHub (SIGIR 2024); the 2025 collection appears at SIGIR 2026.
  • CONE-RAG (SIGIR 2025): gold nuggets for evaluating personalized conversational RAG (paper).
  • LLMJudge: the LLM4Eval relevance-judgment challenge, and Judging the Judges, a collection of LLM-generated relevance judgments (paper).
  • RAVENEA (ICLR 2026): multimodal retrieval-augmented visual culture understanding (paper).
  • MCPQA (EMNLP 2024): multilingual cross-market product question answering.
  • PSCon (SIGIR 2025): product search through conversations.
  • XMarket: cross-market product recommendation data from Amazon, used in the XMRec WSDM Cup (CIKM 2021).
  • ClariQ: the ConvAI3 challenge on clarifying questions in open-domain dialogue (report).
  • Qulac (SIGIR 2019): Questions for Lack of Clarity in open-domain information-seeking conversations.
  • ANTIQUE (ECIR 2020): non-factoid question answering from Yahoo! Answers (paper).
  • ConvKey: keywords from news articles and mixed-initiative conversations for conversational document ranking (paper).
  • CAsTUR (CHIIR 2020): which earlier TREC CAsT 2019 turns are useful context for an utterance (paper).
  • IGLU: the NeurIPS competition on interactive grounded language understanding, with its gridworld environment.

Conversational search and RAG

  • ChatR1 (ACL 2026): reinforcement learning for conversational reasoning and retrieval-augmented QA. Models on Hugging Face.
  • DiSCo (SIGIR 2025): LLM distillation for efficient sparse retrieval in conversational search.
  • Zef-CNP (ECIR 2025): zero-shot clarification need prediction.
  • SimQuAC (WSDM 2024): simulating human-to-human conversational QA with LLMs.
  • MQC (WWW 2024): multimodal clarifying questions.
  • USi (WSDM 2022): user simulator for evaluating mixed-initiative conversational search.
  • PersonalizedCIR (SIGIR 2025): LLM variability in personalized conversational retrieval.

Evaluation and query performance prediction

  • Re-rankers as judges (2026): using re-rankers as relevance judges.
  • LLM-generated rubrics (EACL Findings 2026): LLMs designing and applying evaluation rubrics.
  • QPP-GenRE (TOIS 2025): query performance prediction with LLM-generated relevance judgments.
  • LLMs for relevance judgment (ECIR 2025): improving the reusability of conversational search test collections.
  • RLT4Reranking (SIGIR 2024): ranked list truncation for LLM-based re-ranking.
  • QPP4CS (SIGIR 2023): query performance prediction for conversational search.
  • LLMCrowdDialogueEval (SIGIR 2024) and Effects of Dialogue Context (NAACL Findings 2024): crowdsourced and LLM-based evaluation of dialogue systems.
  • CAUSE (ACL Findings 2024): counterfactual assessment of user satisfaction estimation.
  • CQSatisfaction (EACL Findings 2024): clarifying questions and user satisfaction.
  • ChatGPT-RetrievalQA: synthetic documents for training cross-encoder re-rankers.

Reproducibility studies

  • Hypencoder reproduction (SIGIR 2026)
  • The Power of Noise reproduction (SIGIR 2026)
  • NevIR reproduction (SIGIR 2025)
  • Product-side fairness in bundle recommendation (RecSys 2025)

Recommendation, fairness, and bias

  • Repbias_NBR (ECIR 2025) and TREX (SIGIR 2024): beyond-accuracy next-basket recommendation.
  • MSMGenderBias (ICTIR 2025): LLMs for gender bias detection and mitigation in ranking.
  • Outlier visual saliency (TOIS 2026) and outlier bias (SIGIR 2023): outliers in product search.
  • OMIT (WSDM 2022): fair ranking with outliers.
  • Efficient XMRec (ECIR 2023) and FOREC (CIKM 2021): cross-market recommendation.
  • CalibrationFair (CIKM 2022) and FairRecSys (SIGIR 2022): calibrated and user-oriented fair recommendation.
  • InsightTab (EMNLP Findings 2025): insight distillation for few-shot tabular classification.
  • MIMICS-EL benchmark (ECIR 2021): user engagement prediction for clarification.
  • POI recommendation: SUCP (IP&M 2022), ContextsPOI (TOIS 2022), STACP (ECIR 2020), LGLMF (AIRS 2019).

Multimodal assistants

  • LEGO Co-builder (ICMI 2026): fine-grained vision-language modeling for multimodal assembly assistants.

Mobile search and app usage

  • LSApp: ~600K sequential mobile app usage records from ~300 users (TOIS).
  • ISTAS (CIKM 2018): in situ cross-app mobile search queries collected with uSearch. Project page
  • UniMobile (SIGIR 2018): cross-app mobile search queries. Project page
  • Omicron: the app we used to study user behavior in context (paper).
  • TREC-CS: the collection we crawled for the TREC Contextual Suggestion track.

More code is on GitHub and from IRLab Amsterdam.
