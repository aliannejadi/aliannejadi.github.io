### Shared tasks and test collections

- **[TREC iKAT](https://www.trecikat.com/)**: the TREC Interactive Knowledge Assistance Track, with test collections for personalized conversational search (2023–2025).
- **[XMarket](https://xmrec.github.io/)**: cross-market product recommendation data crawled from Amazon, used in the [XMRec WSDM Cup](https://xmrec.github.io/wsdmcup/). See our [CIKM 2021 paper](https://arxiv.org/abs/2109.05929).
- **[ClariQ](https://github.com/aliannejadi/ClariQ)**: the ConvAI3 challenge data on asking clarifying questions in open-domain dialogues. See the [challenge report](https://arxiv.org/abs/2009.11352).
- **[Qulac](https://github.com/aliannejadi/qulac)**: Questions for Lack of Clarity in open-domain information-seeking conversations, from our SIGIR 2019 paper.
- **[ANTIQUE](https://ciir.cs.umass.edu/downloads/Antique/)**: an open-domain non-factoid question answering benchmark built from Yahoo! Answers ([ECIR 2020](https://arxiv.org/pdf/1905.08957.pdf)).
- **[ConvKey](https://github.com/aliannejadi/ConvKey)**: informative keywords extracted from news articles and mixed-initiative conversations for document ranking in conversational search ([paper](https://arxiv.org/abs/2109.05979)).
- **[CAsTUR](https://github.com/aliannejadi/castur)**: relevance labels identifying which earlier turns of TREC CAsT 2019 conversations are useful context for an utterance ([CHIIR 2020](https://arxiv.org/pdf/1912.10554.pdf)).

### Mobile search and app usage

- **[LSApp](https://github.com/aliannejadi/LSApp)**: ~600K sequential mobile app usage records from ~300 users, complementary to ISTAS ([TOIS paper](https://arxiv.org/pdf/2101.03394)).
- **[ISTAS](https://github.com/aliannejadi/istas)**: in situ cross-app mobile search queries collected with uSearch (CIKM 2018). [Project page]({{ '/istas.html' | relative_url }})
- **[UniMobile](https://github.com/aliannejadi/unimobile)**: cross-app mobile search queries from our SIGIR 2018 paper. [Project page]({{ '/unimobile.html' | relative_url }})
- **[TREC-CS](/data.html#data)**: the collection we crawled for the TREC Contextual Suggestion track.

### Code

- **[OMIT](https://github.com/arezooSarvi/OMIT_Fair_ranking)**: fair ranking with outliers ([WSDM 2022](https://arxiv.org/pdf/2112.11251)).
- **[FOREC](https://github.com/hamedrab/FOREC)**: a cross-market recommendation model ([CIKM 2021](https://arxiv.org/abs/2109.05929)), evaluated on XMarket.
- **[MIMICS-EL benchmark](https://github.com/isekulic/mimics-EL-benchmark)**: user engagement prediction for clarification on MIMICS ([ECIR 2021](https://arxiv.org/pdf/2102.04163.pdf)).
- **[STACP](https://github.com/rahmanidashti/STACP)**: spatio-temporal activity-center POI recommendation ([ECIR 2020](https://aliannejadi.com/papers/20-ecir-poi.pdf)).
- **[LGLMF](https://github.com/rahmanidashti/LGLMF)**: local geographical logistic matrix factorization for POI recommendation ([AIRS 2019](https://arxiv.org/pdf/1909.06667.pdf)).
- **[Omicron](https://github.com/aliannejadi/Omicron)**: the app we used to study user behavior in context ([paper](http://arxiv.org/abs/1812.07081)).
- **[uSearch](https://github.com/aliannejadi/uSearch)**: the app we used to collect in situ cross-app queries ([CIKM 2018](https://aliannejadi.com/papers/cikm2018.pdf)).

More code is on [GitHub](https://github.com/aliannejadi).
